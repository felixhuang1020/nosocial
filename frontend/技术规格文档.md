# NoSocial Admin — 技术规格文档

## 技术栈

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + shadcn/ui
- **Routing**: react-router-dom (v6)
- **State Management**: Zustand
- **Charts**: Recharts
- **Table**: @tanstack/react-table
- **Forms**: react-hook-form + zod
- **Animation**: framer-motion
- **Icons**: lucide-react

  adminUser: { username: string; nickname: string; role: number } | null;

  logout: () => void;
}

interface AppStore {

  toggleSidebar: () => void;
  currentPage: string;
  setCurrentPage: (page: string) => void;
  notifications: Notification[];
  addNotification: (notification: Notification) => void;

interface ToastStore {

}

## 关键实现注意

### 1. 侧边栏折叠
- 使用 Zustand 存储折叠状态
- CSS transition 实现平滑宽度变化
- 折叠时隐藏文字，图标居中
- 桌面端点击汉堡按钮切换，移动端作为抽屉

### 2. 数据表格
- 基于 @tanstack/react-table
- 支持排序、分页、行选择
- 空状态、加载状态骨架屏
- 操作列固定在最右侧

### 3. 图表
- Recharts 的 AreaChart 用于营业额趋势
- BarChart 用于销量排行
- 自定义 Tooltip 样式匹配暗色主题
- 自定义坐标轴颜色和字体

### 4. 模态框管理
- 使用 shadcn Dialog
- 每个页面独立管理模态框状态
- 新增/编辑共用同一表单组件
- 关闭时重置表单

### 5. 图片上传
- 模拟上传（FileReader 读取本地文件）
- 预览功能
- 支持删除
- 多张图片网格展示

### 6. 响应式
- 侧边栏在 < 1024px 自动折叠
- 在 < 768px 变为抽屉覆盖层
- 表格在移动端横向滚动
- 卡片网格响应式列数：4列(大) / 2列(中) / 1列(小)

## 性能优化

- 路由懒加载 (React.lazy + Suspense)
- 图表组件懒加载
- 图片使用懒加载/占位
- Zustand 选择器优化重渲染
- 表格虚拟滚动（数据量大时）
